Pandas for Machine Learning

These notes cover every pandas function you need for the practical component of your Machine Learning course — building the Naive Bayes, regression, decision tree, k-NN, SVM, ANN, and k-means/hierarchical clustering models listed in your syllabus. Each function includes its definition, syntax, common cases, a worked example, and a try-it-yourself exercise.

Why pandas, and not sklearn, in this document? Your syllabus practicals ask you to pull datasets from data.gov.in and the UCI ML repository, then split, clean, and evaluate models. Before any model (Naive Bayes, linear regression, k-NN, SVM, k-means...) ever sees your data, pandas is the tool that loads it, cleans it, selects features, scales it, and splits it. That is exactly the ground these notes cover — nothing here is generic pandas trivia; every function is tied to a specific unit in your syllabus.
Foundation

Pandas Basics — Series & DataFrame

Ties to: Unit 1 — "key elements" of a learning problem are almost always stored as a table of features and a target column. Every dataset you touch this semester (regression, classification, clustering) is loaded as a DataFrame first.

pandas.Series(data, index=None, dtype=None, name=None)

The 1-dimensional building block — think of it as a single labeled column

Definition

A Series is a one-dimensional, labeled array that can hold any data type (numbers, strings, booleans). Every value has an index label attached to it, so it behaves like a cross between a Python list and a dictionary.

Syntax

pd.Series(data, index=None, dtype=None, name=None)
ParameterMeaning
datalist, dict, ndarray, or scalar
indexlabels for each value (defaults to 0,1,2,...)
dtypeforce a data type, e.g. float64
namename of the Series (becomes the column name if added to a DataFrame)

Where it's used

Every single column you pull out of a DataFrame — df['age'], your target/label column y in regression or classification — is a Series.

Example

import pandas as pd

marks = pd.Series([78, 65, 92, 55], index=['Amit','Bina','Chetan','Deepa'], name='Marks')
print(marks)
print(marks['Chetan'])

Output

Amit      78
Bina      65
Chetan    92
Deepa     55
Name: Marks, dtype: int64
92

Common cases

  • Creating a target vector: y = df['species']
  • Creating from a dict — keys become the index automatically
  • Arithmetic works element-wise: marks * 1.1 curves every mark

pandas.DataFrame(data, index=None, columns=None, dtype=None)

The 2-dimensional table — your entire dataset

Definition

A DataFrame is a 2-dimensional labeled table of rows and columns, like a spreadsheet or a SQL table. Columns can hold different data types (numeric, categorical, boolean).

Syntax

pd.DataFrame(data, index=None, columns=None, dtype=None)

Where it's used

This is the object every algorithm in your syllabus consumes: rows = samples/observations, columns = features + a label column. Feature scaling, PCA, train/test splitting, decision trees, k-NN — all operate on a DataFrame (or the NumPy array beneath it).

Example

import pandas as pd

data = {
    'age': [25, 32, 47, 51],
    'salary': [40000, 55000, 82000, 90000],
    'bought_insurance': [0, 0, 1, 1]
}
df = pd.DataFrame(data)
print(df)
print(df.shape)      # (rows, columns)
print(df.columns)    # column names
print(df.dtypes)      # data type per column

Output

   age  salary  bought_insurance
0   25   40000                 0
1   32   55000                 0
2   47   82000                 1
3   51   90000                 1
(4, 3)
Index(['age', 'salary', 'bought_insurance'], dtype='object')
age                 int64
salary              int64
bought_insurance    int64
dtype: object

Common cases

  • From a dict of lists (columns), from a list of dicts (rows), or from a NumPy 2D array
  • df.shape, df.columns, df.index, df.dtypes are attributes, not methods — no parentheses
  • Splitting into features and target: X = df.drop('bought_insurance', axis=1), y = df['bought_insurance'] — this is literally the first line of every classification practical

Unit 1

Loading & Inspecting Data

Ties to: Unit 1 — "applications of ML" and the practicals instruction to use public datasets from data.gov.in and archive.ics.uci.edu/ml/datasets.php. This is always your first step, for every single practical this semester.

pandas.read_csv(filepath, sep=',', header='infer', index_col=None, na_values=None)

Load a dataset from a CSV file into a DataFrame

Definition

Reads a comma-separated (or other delimiter) text file and returns it as a DataFrame. This is how you will load nearly every UCI dataset (Iris, Wine, Breast Cancer, Boston Housing-style regression sets, etc.).

Syntax

pd.read_csv(filepath_or_buffer, sep=',', header='infer',
            names=None, index_col=None, na_values=None, usecols=None)
ParameterMeaning
filepath_or_bufferpath or URL to the file
sepdelimiter — use '\t' for tab-separated UCI files, ';' for some European datasets
headerrow number to use as column names; None if the file has no header row (common in raw UCI .data files)
namessupply column names yourself when header=None
na_valuesstrings to treat as missing, e.g. '?' (UCI datasets often use ? for missing values)
index_colcolumn to use as the row index

Common cases

  • Standard CSV with header: pd.read_csv('iris.csv')
  • Raw UCI .data file, no header, missing values marked '?': pd.read_csv('breast-cancer-wisconsin.data', header=None, na_values='?')
  • Reading directly from a UCI URL: pass the raw URL string instead of a local path
  • Tab-separated: pd.read_csv('data.tsv', sep='\t')

Example

import pandas as pd

# A typical UCI-style load: no header row, '?' marks missing values
cols = ['id','clump_thickness','cell_size','cell_shape','marginal_adhesion',
        'epithelial_size','bare_nuclei','bland_chromatin','normal_nucleoli',
        'mitoses','class']
df = pd.read_csv(
    'https://archive.ics.uci.edu/ml/machine-learning-databases/'
    'breast-cancer-wisconsin/breast-cancer-wisconsin.data',
    header=None, names=cols, na_values='?'
)
print(df.head(3))

Output

        id  clump_thickness  cell_size  ...  mitoses  class
0  1000025                5          1  ...        1      2
1  1002945                5          4  ...        1      2
2  1015425                3          1  ...        1      2

df.head(n=5)  /  df.tail(n=5)

Peek at the first / last rows

Definition

head(n) returns the first n rows; tail(n) returns the last n. Default n is 5. The very first thing you should run after loading any dataset.

Where it's used

Sanity-checking that a dataset loaded with correct columns, correct types, and no obvious misalignment before you do any preprocessing or feed it to a model.

Example

print(df.head())      # first 5 rows
print(df.tail(3))     # last 3 rows

Common cases

  • df.head() with no argument → 5 rows
  • df.head(10) → first 10 rows
  • df.sample(5) is a good companion — a random 5 rows, useful when a dataset is sorted and head() alone would hide diversity

df.describe(include=None)

Summary statistics for every numeric column

Definition

Computes count, mean, std, min, 25/50/75th percentiles, and max for every numeric column. With include='all' or include='object', it also summarizes categorical columns (count, unique, top, freq).

Where it's used

Directly relevant to Unit 2's feature scaling: describe() tells you the scale/range of each feature, which is exactly why algorithms like k-NN, k-means, and gradient descent-based regression need scaling — a feature ranging 0–90000 (salary) will dominate one ranging 0–1 (a ratio) unless scaled.

print(df.describe())

Common cases

  • df.describe() — numeric columns only (default)
  • df.describe(include='object') — categorical columns only
  • df.describe(include='all') — everything, with NaN in cells that don't apply
  • Comparing min/max across columns tells you immediately which features need scaling before k-NN, SVM, or k-means

Unit 2

Handling Missing & Duplicate Data

Ties to: Unit 2 — Preprocessing. Real UCI datasets (e.g. Breast Cancer Wisconsin) ship with missing values; models like linear/logistic regression, SVM, and k-NN cannot handle NaN directly.

df.isnull()  /  df.notnull()

Detect missing values, cell by cell

Definition

isnull() returns a same-shaped DataFrame of booleans: True where a value is missing (NaN). notnull() is the exact opposite.

Syntax

df.isnull()                # full boolean grid
df.isnull().sum()           # missing count per column  (most-used form)
df.isnull().sum().sum()     # total missing values in the whole DataFrame
df['col'].isnull()          # boolean mask for one column

Example

print(df.isnull().sum())

Output

id                  0
clump_thickness     0
bare_nuclei        16
class               0
dtype: int64

Common cases

  • df.isnull().sum() — the standard first check, column-wise missing counts
  • df[df['bare_nuclei'].isnull()] — view the actual rows that are missing that feature
  • df.isnull().any() — which columns have at least one missing value (True/False per column)
Try it — Exercise

Given a DataFrame with missing values in two columns, print (a) the total missing count per column, and (b) the rows where both of those columns are missing at once (hint: combine two boolean masks with &).

df.dropna(axis=0, how='any', subset=None, inplace=False)

Remove rows (or columns) containing missing values

Definition

Drops any row (default) or column that contains missing values, according to the how rule.

Syntax

df.dropna(axis=0, how='any', subset=None, inplace=False)
ParameterMeaning
axis0 = drop rows (default), 1 = drop columns
how'any' = drop if any value missing; 'all' = drop only if every value in the row/col is missing
subsetonly consider these columns when deciding to drop a row
inplaceif True, modifies df directly instead of returning a new one

Example

print(df.shape)                 # (699, 11)
df_clean = df.dropna()
print(df_clean.shape)            # (683, 11) -- 16 rows removed

Common cases

  • Drop rows with any missing value: df.dropna() — safe default for small amounts of missingness
  • Drop only if a specific column is missing: df.dropna(subset=['bare_nuclei'])
  • Drop a column that is mostly empty: df.dropna(axis=1, thresh=len(df)*0.5) — keeps only columns with at least 50% non-null data
When to prefer dropna() over fillna(): use it when missing values are rare (a small % of rows) so you don't lose much signal. If a large fraction of a column is missing, imputing with fillna() usually preserves more data for training your regression/classification model.
Try it — Exercise

Load the Breast Cancer Wisconsin dataset (it has 16 missing values in bare_nuclei marked as '?'). Drop the affected rows and confirm the new shape has exactly 683 rows.

df.fillna(value=None, method=None, inplace=False)

Impute missing values instead of deleting rows

Definition

Replaces NaN values with a specified value, a computed statistic, or by forward/backward filling from neighboring rows.

Syntax

df['col'].fillna(value, inplace=False)
df['col'].fillna(df['col'].mean())     # impute with the mean (regression-friendly)
df['col'].fillna(df['col'].median())   # impute with the median (robust to outliers)
df['col'].fillna(df['col'].mode()[0])  # impute with the mode (categorical columns)
df.fillna(method='ffill')               # forward-fill from the previous row
df.fillna(method='bfill')               # backward-fill from the next row

Example

df['bare_nuclei'] = df['bare_nuclei'].fillna(df['bare_nuclei'].median())
print(df['bare_nuclei'].isnull().sum())   # 0

Common cases

  • Numeric feature, no strong outliers → fill with mean()
  • Numeric feature with outliers (e.g. income) → fill with median(), which is not skewed by extreme values
  • Categorical feature (e.g. a "yes/no" column) → fill with mode()[0], the most frequent category
  • Time-ordered data → ffill/bfill carries the last known value forward/backward
Try it — Exercise

On the same Breast Cancer dataset, instead of dropping rows, impute the missing bare_nuclei values with the column median. Compare df.describe() before and after — has the mean shifted much?

df.duplicated(subset=None)  /  df.drop_duplicates(subset=None)

Find and remove repeated rows

Definition

duplicated() returns a boolean Series flagging rows that are exact repeats of an earlier row. drop_duplicates() removes them, keeping the first occurrence by default.

Syntax

df.duplicated()                 # boolean flag per row
df.duplicated(subset=['id'])    # duplicate check on specific column(s) only
df.drop_duplicates(keep='first')

Where it's used

Duplicate samples silently bias model training — a repeated row gets "double weight" during fitting and can leak between your train and test split if not removed first. Always check before splitting for Unit 3/4 practicals.

Example

print(df.duplicated().sum())     # how many duplicate rows exist
df = df.drop_duplicates()

Common cases

  • Duplicate on all columns (default) — an exact repeated record
  • Duplicate on a subset, e.g. subset=['patient_id'], to catch the same patient entered twice even if one field differs
Try it — Exercise

Append 3 duplicate rows to any small DataFrame you build. Confirm duplicated().sum() reports 3, then remove them and confirm the row count drops back to the original.

Unit 2

Selection, Filtering & Feature Selection

Ties to: Unit 2 — "feature selection methods." Before PCA or any model, you need to pick out relevant columns/rows, drop irrelevant ones, and isolate features from the label.

df.loc[row_labels, column_labels]

Label-based selection

Definition

Selects rows and columns by their label (index name / column name), not position. Supports slicing, boolean masks, and lists of labels. Note: with loc, slice endpoints are inclusive.

Syntax

df.loc[row_selector, column_selector]
df.loc[0:3, 'age']                 # rows 0-3 inclusive, one column
df.loc[:, ['age','salary']]        # all rows, specific columns
df.loc[df['age'] > 40, 'salary']   # conditional selection

Example

print(df.loc[0:2, ['age','salary']])
print(df.loc[df['age'] > 40, 'salary'])

Output

   age  salary
0   25   40000
1   32   55000
2   47   82000
2    82000
3    90000
Name: salary, dtype: int64

Common cases

  • Select all rows, a list of feature columns: df.loc[:, ['sepal_length','sepal_width']]
  • Filter + select in one step: df.loc[df['class']==1, 'age']
  • Set values conditionally: df.loc[df['age']<0, 'age'] = 0 (clip invalid data)
Try it — Exercise

From the Iris dataset, use .loc to select just the petal_length and petal_width columns for rows where species == 'Iris-setosa'.

df.iloc[row_positions, column_positions]

Position-based (integer index) selection

Definition

Selects rows and columns by integer position, exactly like NumPy/Python list slicing. Slice endpoints are exclusive (unlike loc).

Syntax

df.iloc[row_positions, column_positions]
df.iloc[0:5, 0:3]     # first 5 rows, first 3 columns
df.iloc[:, :-1]        # all rows, all columns EXCEPT the last (common: features)
df.iloc[:, -1]         # all rows, ONLY the last column (common: target)

Where it's used

This is the classic one-liner for splitting features from target when the target is the last column — extremely common with raw UCI files that have no column names:

Example

X = df.iloc[:, :-1].values   # every column except the last -> features
y = df.iloc[:, -1].values     # last column only -> target/label
print(X.shape, y.shape)

Output

(699, 10) (699,)

Common cases

  • df.iloc[:, :-1] — all features (drop last column)
  • df.iloc[:, -1] — target column only
  • df.iloc[0:100] — first 100 rows (e.g. a quick train subset)
  • df.iloc[-10:] — last 10 rows
Try it — Exercise

Using iloc, split any loaded dataset into X (all columns except the last) and y (last column only), then print both shapes.

Boolean indexing: df[condition]

Filter rows using a logical condition

Definition

Passing a boolean Series (produced by a comparison on a column) inside square brackets returns only the rows where the condition is True. Combine multiple conditions with & (and), | (or) — each condition must be wrapped in parentheses.

Syntax

df[df['col'] > value]
df[(df['col1'] > v1) & (df['col2'] == v2)]
df[df['col'].isin([v1, v2, v3])]

Example

older_high_earners = df[(df['age'] > 30) & (df['salary'] > 50000)]
print(older_high_earners)

Output

   age  salary  bought_insurance
2   47   82000                 1
3   51   90000                 1

Common cases

  • Class-balance check before classification: df[df['class']==1].shape[0] vs. df[df['class']==0].shape[0]
  • Removing invalid rows: df = df[df['age'] > 0]
  • isin() for multi-value membership tests, useful for keeping only certain classes in a multi-class dataset

df.drop(labels=None, axis=0, columns=None, inplace=False)

Remove columns or rows

Definition

Returns a new DataFrame with the specified row(s) or column(s) removed.

Syntax

df.drop('col_name', axis=1)          # drop one column
df.drop(columns=['c1','c2'])          # drop multiple columns (clearer syntax)
df.drop([0, 1, 2], axis=0)            # drop rows by index label

Where it's used

The standard way to separate features (X) from the target (y) by name instead of position, and to remove irrelevant columns (e.g. an ID column) that would otherwise be treated — wrongly — as a predictive feature.

Example

X = df.drop(columns=['id', 'class'])   # features only
y = df['class']                          # target only
print(X.columns.tolist())

Common cases

  • Dropping an ID column that has no predictive meaning before training any model
  • Dropping the target column to build X
  • axis=1 (or columns=) for columns, axis=0 (default) for rows

df.select_dtypes(include=None, exclude=None)

Grab only columns of a certain data type

Definition

Returns a subset of the DataFrame containing only columns matching the given dtype(s). Useful for separating numeric features (which may need scaling / PCA) from categorical ones (which need encoding).

Syntax

df.select_dtypes(include=['number'])     # all numeric columns
df.select_dtypes(include=['object'])     # all text/categorical columns

Example

numeric_cols = df.select_dtypes(include=['number']).columns
categorical_cols = df.select_dtypes(include=['object']).columns
print(numeric_cols.tolist())
print(categorical_cols.tolist())

Common cases

  • Automatically build a list of numeric columns to feed into feature scaling (Unit 2) without hardcoding names
  • Automatically build a list of categorical columns to one-hot encode with get_dummies()

Unit 2 & 4

Scaling, Encoding & Transforming

Ties to: Unit 2 — "feature scaling" and dimensionality reduction (PCA needs scaled input); Unit 4 — classifiers like Naive Bayes and decision trees need categorical features encoded numerically.

df.apply(func, axis=0)  /  Series.apply(func)

Apply any custom function across rows, columns, or a single Series

Definition

Runs a function along an axis of the DataFrame (axis=0 = down each column, axis=1 = across each row), or element-wise on a single Series. Accepts built-in functions, lambdas, or your own custom functions.

Syntax

df['col'].apply(func)             # element-wise on one column
df.apply(func, axis=0)             # func receives each COLUMN as a Series
df.apply(func, axis=1)             # func receives each ROW as a Series

Example

# Feature engineering: turn continuous age into a category (Unit 4 prep)
def age_group(age):
    if age < 30: return 'young'
    elif age < 50: return 'middle'
    else: return 'senior'

df['age_group'] = df['age'].apply(age_group)

# Row-wise: compute a ratio feature from two columns
df['salary_per_age'] = df.apply(lambda row: row['salary'] / row['age'], axis=1)
print(df[['age','age_group','salary_per_age']])

Common cases

  • Single-column transform: df['col'].apply(lambda x: x**2)
  • Row-wise feature engineering combining multiple columns: axis=1
  • Binning a continuous variable into categories before classification
Try it — Exercise

Write a function that labels a numeric score column as 'pass' if ≥ 40, else 'fail'. Apply it to create a new column, then use value_counts() to see the pass/fail split.

Series.map(arg)

Element-wise substitution using a function, dict, or Series

Definition

Substitutes each value in a Series according to a mapping — a function, a dictionary of old→new values, or another Series. Simpler and often faster than apply() for pure lookup-style replacement, and works only on a Series (not a whole DataFrame).

Syntax

df['col'].map({'old1':'new1', 'old2':'new2'})
df['col'].map(lambda x: x.upper())

Where it's used

The classic way to manually encode a binary/ordinal categorical target before Naive Bayes, logistic regression, decision trees, etc., when you want explicit control over which label maps to which number (unlike the automatic alphabetical mapping get_dummies() would apply).

Example

df['class'] = df['class'].map({2: 0, 4: 1})   # UCI encodes benign=2, malignant=4
print(df['class'].value_counts())

Output

0    458
1    241
Name: class, dtype: int64

Common cases

  • Recoding a target's raw class labels into clean 0/1 for binary classification
  • Mapping abbreviations to full names for readability, e.g. {'M':'Male','F':'Female'}

Manual feature scaling with pandas (Min-Max & Standardization)

The pandas-only way to scale features — no sklearn required

Definition

Feature scaling brings all numeric columns to a comparable range. Two formulas matter for this syllabus (Unit 2, 6.1.1/6.1.2):

  • Min-Max normalization → squeezes values into [0, 1]: (x - min) / (max - min)
  • Standardization (Z-score) → mean 0, std 1: (x - mean) / std

Syntax

# Min-Max scaling, column by column
df_norm = (df - df.min()) / (df.max() - df.min())

# Standardization (z-score)
df_std = (df - df.mean()) / df.std()

Example

features = ['age', 'salary']

# Min-max
df_norm = df[features].copy()
df_norm = (df_norm - df_norm.min()) / (df_norm.max() - df_norm.min())
print(df_norm)

# Standardization
df_std = df[features].copy()
df_std = (df_std - df_std.mean()) / df_std.std()
print(df_std)

Output (Min-Max, for the earlier age/salary example)

        age    salary
0  0.000000  0.000000
1  0.269231  0.300000
2  0.846154  0.840000
3  1.000000  1.000000

Common cases

  • Use Min-Max when you need bounded [0,1] values, e.g. before k-NN or k-means, where raw distance calculations are sensitive to feature range
  • Use Standardization before algorithms that assume roughly normal, zero-centered data — SVM, logistic regression, PCA (Unit 2, 12.2), and gradient-descent-based linear regression (Unit 3) converge faster and more reliably on standardized features
  • Always fit scaling parameters (min/max or mean/std) on the training set only, then apply the same parameters to the test set — never recompute them on test data (this avoids "data leakage")

pandas.get_dummies(data, columns=None, drop_first=False)

One-hot encode categorical columns

Definition

Converts a categorical column into multiple binary (0/1) columns, one per category. Required because most ML algorithms in this syllabus (SVM, logistic regression, k-NN, neural networks) need purely numeric input.

Syntax

pd.get_dummies(df, columns=['species'], drop_first=False)
ParameterMeaning
columnswhich categorical column(s) to encode
drop_firstdrop one dummy column per feature to avoid redundant/collinear columns (recommended for linear/logistic regression)

Example

iris_encoded = pd.get_dummies(iris_df, columns=['species'], drop_first=True)
print(iris_encoded.columns.tolist())

Output

['sepal_length', 'sepal_width', 'petal_length', 'petal_width',
 'species_Iris-versicolor', 'species_Iris-virginica']

Common cases

  • Nominal categories with no order (color, city, species) → one-hot encode with get_dummies()
  • drop_first=True for linear/logistic regression, to avoid the "dummy variable trap" (perfectly correlated columns)
  • Ordinal categories with a real order (low/medium/high) → prefer .map() to assign 0/1/2 rather than one-hot encoding, since order carries meaning

Definition

Replaces occurrences of a value (or list of values) with another value, across a Series or the whole DataFrame. More flexible than map() because it can target values without replacing everything else with NaN.

Definition

Casts a Series or DataFrame to a specified dtype, e.g. object → float64, or int → category.

Randomly sample rows — the pandas-only way to train/test split

Definition

pandas.concat(objs, axis=0, ignore_index=False)

Stack DataFrames together, vertically or side by side

Definition

Concatenates a list of DataFrames along an axis: axis=0 stacks rows on top of each other (same columns), axis=1 places them side by side (same rows, different columns).

Syntax

pd.concat([df1, df2], axis=0, ignore_index=True)   # stack rows
pd.concat([df1, df2], axis=1)                       # join columns side-by-side

Where it's used

Recombining a scaled feature set with an untouched target column after processing them separately, or merging results from k-fold cross-validation splits back together for reporting.

Example

X_scaled = (X - X.mean()) / X.std()          # scaled features
final_df = pd.concat([X_scaled, y], axis=1)   # reattach the target column
print(final_df.head())

Common cases

  • axis=0 — combining multiple CSV files of the same structure (e.g. multiple months of a dataset) into one DataFrame
  • axis=1 — reattaching a target column after scaling only the feature columns
  • ignore_index=True — re-numbers the index cleanly after stacking rows, avoiding duplicate index labels

pandas.merge(left, right, on=None, how='inner')

SQL-style join of two DataFrames on a common key

Definition

Combines two DataFrames based on matching values in one or more shared columns (a "key"), similar to a SQL JOIN.

Syntax

pd.merge(left, right, on='key_column', how='inner')
howMeaning
'inner'keep only keys present in both DataFrames (default)
'left'keep all rows from the left DataFrame, matching where possible
'right'keep all rows from the right DataFrame
'outer'keep all rows from both, filling gaps with NaN

Example

patients = pd.DataFrame({'patient_id':[1,2,3], 'age':[45,60,32]})
diagnosis = pd.DataFrame({'patient_id':[1,2,3], 'class':[0,1,0]})

print(full)

Output

0           1   45      0
1           2   60      1
2           3   32      0

Common cases

  • Joining a feature table and a label table that were provided as two separate files sharing an ID column — common with government open datasets on data.gov.in
  • how='left' when you want to keep every record from your main table even if some auxiliary info is missing

Series.value_counts(normalize=False)

Frequency count of each unique value

Definition

Returns the count of each unique value in a Series, sorted descending by default. With normalize=True, returns proportions instead of raw counts.

Syntax

df['class'].value_counts()
df['class'].value_counts(normalize=True)   # as percentages (0-1)

Where it's used

The standard first check for class imbalance before training any classifier (Unit 4) — a 90/10 class split needs different handling (e.g. stratified sampling, different evaluation metrics) than a balanced 50/50 split.

Example

print(df['class'].value_counts(normalize=True))

Output

0    0.655
1    0.345
Name: class, dtype: float64

Common cases

  • Checking class balance before choosing evaluation metrics — with imbalance, accuracy alone is misleading and metrics like Recall, F1-score, and AUC (as your syllabus specifies) matter more
  • Counting categories in a categorical feature before deciding whether to one-hot encode (few categories) or group rare ones together (many categories)

Capstone Exercise — Full Preprocessing Pipeline

Combine everything above into one end-to-end pipeline, exactly as you'll need to for your practical file. Pick any one of these UCI datasets: Breast Cancer Wisconsin (classification), Wine Quality (regression), or Iris (classification/clustering).

Steps

  1. Load the dataset with read_csv(), handling missing-value markers with na_values.
  2. Inspect with head(), info(), and describe().
  3. Clean: check isnull().sum(); impute or drop as appropriate with fillna()/dropna(). Remove duplicates with drop_duplicates().
  4. Select features: drop irrelevant columns (IDs) with drop(); use corr() to identify weakly-related features to consider removing.
  5. Encode any categorical columns with get_dummies() or .map().
  6. Scale numeric features with the standardization formula.
  7. Check balance of the target with value_counts(normalize=True) (classification) — or check its distribution with describe() (regression).
  8. Split into train/test with sample() + drop() (or hand off X/y built with iloc to sklearn.model_selection.train_test_split for your actual practical).
  9. Hand off the cleaned, scaled X_train, X_test, y_train, y_test to whichever model your practical requires — Naive Bayes, linear/logistic regression, k-NN, decision tree, SVM, or k-means — this is where pandas' job ends and the model-fitting begins.
import pandas as pd
import numpy as np

# 1. Load
df = pd.read_csv('dataset.csv', na_values='?')

# 2. Inspect
print(df.info())
print(df.describe())

# 3. Clean
df = df.drop_duplicates()
df['col_with_gaps'] = df['col_with_gaps'].fillna(df['col_with_gaps'].median())

# 4. Select features
df = df.drop(columns=['id'])

# 5. Encode (if a categorical column exists)
df = pd.get_dummies(df, columns=['categorical_col'], drop_first=True)

# 6. Scale
target = df['target']
features = df.drop(columns=['target'])
features_scaled = (features - features.mean()) / features.std()

# 7. Check target balance / distribution
print(target.value_counts(normalize=True))

# 8. Split
train_idx = features_scaled.sample(frac=0.8, random_state=42).index
X_train, X_test = features_scaled.loc[train_idx], features_scaled.drop(train_idx)
y_train, y_test = target.loc[train_idx], target.drop(train_idx)

print(X_train.shape, X_test.shape)

# Practical List of AADS
1. Write a program to implement following vector operations: at(i), insert (i,e), erase(i,e), set(i,e), push_back(), pop_back().
2. Write a cpp program to implement a vector and perform extended array (Insertion,  deletion) operations using vector class.
3. list after k rotations
4. Given a vector of integers and a target value, return the indices of two numbers whose sum equals the target (2Sum).
5. Write a C++ program to remove duplicate elements from a sorted vector of integers.
6. Implement a push function. Start with an array size of 2. If a student pushes an item into a full stack, create a new array that is double the size. Copy all old items over.
7. Track the exact number of operations. For a normal push, the cost is 1. For a resizing push, the cost is 1 plus the number of copied items.
8. Push 1,000 items in a loop. Print out the total cost and the average cost per push at the very end.
9. Change the resizing rule. Instead of doubling, increase the size by adding +10 slots each time it fills up. Run 1,000 pushes again. Compare the average costs of both methods.
10. Given a sorted vector, remove duplicates in-place and return the number of unique elements.
11. Find the common elements between two vectors.
12. Given a vector of integers, create two vectors: one containing even numbers and another containing odd numbers.
13. Count how many times each element occurs in a vector.

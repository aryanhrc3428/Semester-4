algo{
BFS(s):
    Set Discovered[s] = true and Discovered[v] = false for all other v
    Initialize L[0] to consist of the single element s
    Set the layer counter i = 0
    Set the current BFS tree T = ∅
    While L[i] is not empty
        Initialize an empty list L[i + 1]
        For each node u ∈ L[i]
            Consider each edge (u, v) incident to u
            If Discovered[v] = false then

            Endif
        Endfor
        Increment the layer counter i by one
    Endwhile
}

algo{

11. prim's algorithm
algo{
Prim(G):
    Initialize S to be an empty set
    Initialize Q to be a priority queue
    For each node v in V
        Set a[v] = infinity
        Set edgeTo[v] = null
        Insert v into Q with key a[v]
    Endfor
    Choose an arbitrary starting node s
    Set a[s] = 0
    ChangeKey(Q, s, a[s])
    While Q is not empty
        Take a node u from Q using ExtractMin(Q)
        Add u to S
        For each edge (u, v) incident to u
            If v is not in S then
                If cost(u, v) < a[v] then
                    Set a[v] = cost(u, v)
                    Set edgeTo[v] = u
                    ChangeKey(Q, v, a[v])
                Endif
            Endif
        Endfor
    Endwhile
    Return edgeTo
}
- theorem(4.22): Using a priority queue, Prim’s Algorithm can be implemented on a graph with n nodes and m edges to run in O(m) time, plus the time for n ExtractMin, and m ChangeKey operations.
